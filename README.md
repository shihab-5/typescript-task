Introduction

In this assignment, I practiced different TypeScript concepts through 8 practical problems. The main goal was to understand how TypeScript works and how to use its features in real coding situations.

Topics I Worked On

Default Parameters: Using optional parameters and default values in functions.

Union Types: Accepting multiple types of values in a single function.

Type Narrowing: Checking types using typeof before performing operations.

Readonly Tuples: Working with fixed-position values and preventing modification.

Generics: Creating reusable functions that work with different types.

Interfaces: Defining object structures with specific properties and types.

Keyof & Indexed Access Types: Accessing object properties safely using generic types.

Classes & Inheritance: Understanding constructors, extends, and super.

Access Modifiers: Working with private and protected properties.

Promises & Async/Await: Handling asynchronous operations using resolve, reject, and setTimeout.
